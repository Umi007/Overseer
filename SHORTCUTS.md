# Neovim shortcuts

## Opening menus

Press in normal mode and wait a moment.

| Keys | Shows |
|---|---|
| `Space` | Main menu |
| `Space` + letter | One group from the main menu, such as `Space w` for windows or `Space x` for diagnostics |
| `g` | Go-to commands |
| `z` | Folding and scrolling |
| `[` or `]` | Jump to the previous or next item |
| `Ctrl + W` | Window commands |
| `"` | Saved text registers |

## Inside a menu

| Keys | Does |
|---|---|
| `Ctrl + D` | Scroll down |
| `Ctrl + U` | Scroll up |
| Group's letter | Go forward one u, into that group |
| `Backspace` | Go back one menu |
| `Esc` | Close |

## Searching

| Keys | Does |
|---|---|
| `Space s k` | Search all keymaps |
| `Space ?` | Show keymaps for the current file |
